# SwarmWorld Operations & Game Guide

## Getting Started
1. **Simulation Control**:
   - Use the minimal top-tier playback controls to step (Single World Tick), play (1x, 2x, 5x, 10x speeds), or freeze the world.
   - Switch between **BioFoundry**, **AshenRealm**, and **Protein Realms** to observe how material constraints dictate technological specialization.
2. **Experimental Conditions**:
   - Toggle between **Full Culture**, **No Communication**, **No Explicit Culture**, and **Independent Search** to benchmark the bounded swarm advantage.
3. **Interactive Tools**:
   - **World View**: Inspect agents, inspect persistent artifacts, view environmental field layers (Moisture, Contamination, Thermal, Nutrient), and trigger disturbances.
   - **Material Workbench**: Formulate custom bio-composites, configure sensor-actuator controllers, run standardized mechanical test assays, and build persistent installations.
   - **Knowledge Lineage**: Trace the provenance of ideas, code forks, and multi-agent collaborations.
   - **Held-Out Resilience Assay**: Execute agent-free stress testing under 8 unseen disturbance scenarios to evaluate true technological durability.
   - **Challenges & Missions**: Complete structured research campaigns ranging from "First Stigmergic Lattice" to "3,200-Tick Resilience Mastery".
4. **Cloud Sync & Leaderboards**:
   - Export and import simulation snapshots across devices via base64 encoded profile sync or direct JSON backup.
   - Compete on standard world seeds (3201, 3202, 3301, 1703, 3801) across Portfolio Resilience and Invention counts.
